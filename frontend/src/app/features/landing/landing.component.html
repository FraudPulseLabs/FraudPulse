Technical capabilities

Built for decisions, not dashboards alone.

Ingestion

REST transaction API

FastAPI endpoints validate and persist card payment payloads, then hand them to the scoring and decision pipeline.

Scoring

Calibrated LightGBM

Real-time feature extraction feeds a calibrated LightGBM model that outputs a fraud risk score for each transaction.

Operations

Cases & alerts

REVIEW and BLOCK outcomes create alerts and cases so analysts can investigate flagged payments in the dashboard.

Architecture

Modular pipeline from ingest to decision.

FastAPI backend on Oracle Cloud, Angular dashboard on Render, and Postgres storage through Supabase. Transactions move from REST ingestion to feature extraction, calibrated model scoring, and ALLOW / REVIEW / BLOCK routing.
